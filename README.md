# Система управления пользователями (WPF + EF)

Учебный проект на WPF + Entity Framework 6 + MS SQL Server  
Реализовано разграничение прав, фильтрация, сортировка и управление пользователями.

## Ветки репозитория
- **Project** — весь исходный код проекта (открывать `Project1.sln`)
- **DataBase** — только дамп базы `Дамп.sql`

## Как запустить проект

1. Скачать и восстановить базу:
   - Перейти в ветку **DataBase**
   - Скачать файл `Дамп.sql`
   - Открыть SSMS → правой кнопкой по «Databases» → New Query → вставить содержимое дампа → выполнить
   (или через Tasks → Generate Scripts → если у вас .bak)

2. Скачать код:![Uploading ДобНовогоПольз.png…]()

   - Перейти в ветку **Project**
   - Скачать ZIP или `git clone`
   - Открыть `Project1.sln` в Visual Studio 2022+

3. Нажать **F5**

### Тестовые учётные данные
- Администратор: `Admin` / любой пароль из базы  
- Менеджер: `Менеджер` / любой  
- Гость: кнопка «Войти гостем»
